# Irmandade Transportadora — versão estática

Este pacote contém somente HTML, CSS e JavaScript, pronto para hospedagem estática (por exemplo, GitHub Pages).

## Arquivos
- `index.html`: estrutura do site
- `style.css`: estilos
- `app.js`: interações locais no navegador

## Limitações importantes
Esta versão não possui servidor, API ou banco de dados. Os relatos da Ouvidoria ficam apenas no armazenamento local do navegador/dispositivo e não são enviados à equipe. Login, cadastro, painel administrativo, aprovação de usuários, agendamentos, ponto, uploads e rastreamento real não funcionam nesta versão. Não use armazenamento local para dados pessoais ou operações reais.

Para recuperar essas funções será necessário conectar o site a um backend e banco de dados.
